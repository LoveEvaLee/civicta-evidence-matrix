# README에 첨부한 30초 안팎 도구 시연영상

> `media/intro.mp4` — 배포 주소(https://morins.github.io/civicta-evidence-matrix/)를 1280×720으로 녹화하고, 내레이션은 팀원 본인 목소리(Qwen3-TTS 보이스 클론)로 합성해 넣었다. 녹화일 2026-10-18, main `4be398c` 기준.

| 장면 | 화면 | 해설(자막) |
|---|---|---|
| 1 | 타이틀 카드 → 사이트 첫 화면 → 입력 패널 | CivicTA는 시민참여 기술영향평가 연구를 정책 단계와 HCI 차원으로 비교하는 도구입니다. |
| 2 | '실존 문헌 16편 불러오기' → 5×4 매트릭스 | 실존 문헌 16편을 불러오면 매트릭스에 근거 분포가 나타납니다. 0은 이 표본에서 관찰되지 않았다는 뜻입니다. |
| 3 | 방향키로 칸 이동 → Enter → 근거 문헌 5편 | 칸을 누르면 연결된 문헌이 보이고, 키보드만으로도 이동할 수 있습니다. |
| 4 | 자동화 견본 6편 → 다른 2편을 사람이 고침 → 확정 → 매트릭스 추가 | AI는 코딩을 추천만 하고, 사람이 확정한 문헌만 집계에 들어갑니다. |
| 5 | 분석 보고서(.md) 내보내기 → 끝 카드 | 결과는 분석 범위와 미분류 사유를 담은 보고서로 내보냅니다. |

- 장면 3은 마우스 없이 키보드(↓↓→ Enter)로만 조작했다(이슈 #5 완료 기준).
- 장면 4의 자동화는 API 키 없는 샘플 모드다. 실제 API 키는 영상에 넣지 않았다.
- 내레이션의 숫자·영문은 읽는 대로 한글로 풀어 합성했다(16편 → 열여섯 편, HCI → 에이치씨아이).
